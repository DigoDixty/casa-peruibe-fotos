# 🏠 Fotos Casa Peruíbe - Organizador de Ambientes

Aplicação web interativa para visualização, classificação e organização de fotos da Casa de Peruíbe por ambientes (Piscina, Corredor das Plantas, Área Gourmet, etc.).

## ☁️ Armazenamento em Nuvem
* **Imagens & Thumbnails:** Hospedados no **Azure Blob Storage** com SAS Token estendido.
* **Segurança:** Protegido por senha de edição (`Pandora01@`). Visitantes acessam em modo somente leitura (protegido contra alterações acidentais).

## 🚀 Recursos
* Modo de cards agrupados por ambientes / referências.
* Reordenação fácil de cards (drag & drop ou setas ◀ ▶).
* Drag & drop de fotos entre ambientes.
* Visualização em tela cheia (Lightbox) com zoom e alta resolução.
* Geração de relatórios com links diretos no Azure para envio via WhatsApp ou laudo.
